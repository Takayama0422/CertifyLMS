# 動作確認の証跡

各 Issue / PR の動作確認で撮影したスクリーンショットと動画を置いている。

**このブランチはコードを含まない。** `main` / `develop` および各 `feature/*` とは独立しており、
どこへもマージしない。Issue / PR のコメントから画像を参照するためだけに存在する。

## 構成

```
issues/<Issue番号>_<チケットID>/
├── before/   修正前
└── after/    修正後
```

`before` と `after` は同じシナリオを同じ手順で実行して撮影している。
画面を持たないチケットは、コマンドの実行結果などをテキストで置いている。
